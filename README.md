畫幅截圖是一款 Windows 截圖工具，支援自由比例、固定比例框選，以及單一螢幕或整個桌面的擷取。

- 框選後可拖曳調整位置，按「確認」完成截圖。
- 可預覽截圖，並將 PNG 或 JPEG 儲存到指定位置。
- 程式可常駐系統匣。雙擊圖示重新開啟，或按右鍵選擇「結束程式」。
  
ScreenCrop is a Windows screenshot tool that captures a freeform region, a region at a fixed aspect ratio, a single monitor, or the entire desktop.

- Drag to reposition the selection, then click (Confirm).
- Preview your screenshot and save it as a PNG or JPEG in a folder of your choice.
- Keep the app running in the system tray. Double-click the icon to reopen it, or right-click and choose (Exit).
